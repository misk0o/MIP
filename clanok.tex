\begin{abstract}
Tento článok prezentuje návrh webovej aplikácie TimeManager (TIMA), ktorá kombinuje princípy efektívneho time managementu s modernými technológiami a integráciou Google služieb. Aplikácia je určená primárne študentom a využíva umelú inteligenciu (Google Gemini) na inteligentné plánovanie úloh. Systém je postavený na Next.js frontende s Django backend-om a PostgreSQL databázou, čo zabezpečuje škálovateľnosť a vysoký výkon.
\end{abstract}

\section{Úvod a motivácia}

Moderný študent čelí náročnej úlohe balansovať medzi akademickými povinnosťami, osobným rastom a voľnočasovými aktivitami. Podľa prieskumu \cite{time-management-students} až 68\% vysokoškolských študentov uvádza problémy s efektívnym plánovaním času, čo vedie k zvýšenému stresu a nižšej produktivite.

Existujúce riešenia ako Todoist, Microsoft To Do či Google Tasks ponúkajú základnú funkcionalitu správy úloh, no často im chýba inteligentná prioritizácia a integrácia s akademickým prostredím. TimeManager sa snaží preklenúť túto medzeru kombináciou osvedčených metód time managementu s modernou AI technológiou.

\section{Súčasný stav riešenia}

\subsection{Metódy time managementu}

V oblasti time managementu existuje niekoľko osvedčených prístupov. \textbf{Eisenhowerova matica} kategorizuje úlohy podľa dôležitosti a naliehavosti do štyroch kvadrantov, čo umožňuje efektívnu prioritizáciu \cite{eisenhower}. \textbf{Pomodoro technika} využíva 25-minútové intervaly práce s krátkymi prestávkami na udržanie koncentrácie \cite{pomodoro}.

\subsection{Existujúce aplikácie}

Súčasný trh ponúka množstvo plánovacích aplikácií. Google Calendar poskytuje vynikajúcu správu udalostí, no chýba mu podpora pre projektové úlohy. Notion ponúka komplexný workspace, ale je príliš zložitý pre jednoduchý time management. Todoist exceluje v správe úloh, no nemá natívnu integráciu s akademickými systémami.

\section{Problémová oblasť}

Hlavným problémom je \textbf{fragmentácia nástrojov} – študenti musia prepínať medzi viacerými aplikáciami (kalendár, úlohy, poznámky), čo znižuje efektivitu. Druhý významný problém je \textbf{nedostatok kontextuálnej inteligencie} – existujúce nástroje nereagují na aktuálnu záťaž používateľa ani neposkytujú adaptívne odporúčania.

Zároveň chybí \textbf{integrácia s akademickým prostredím} – prepojenie s rozvrhovými systémami škôl, sledovanie deadlinov semestrálnych prác či koordinácia skupinových projektov.

\section{Návrh riešenia}

\subsection{Architektúra systému}

TimeManager využíva modernú trojvrstvovú architektúru:

\textbf{Frontend} je implementovaný v Next.js 14 s využitím App Router, React Server Components a TypeScript pre type-safety. Tailwind CSS zabezpečuje responzívny dizajn a shadcn/ui poskytuje konzistentné UI komponenty s prístupnosťou (accessibility).

\textbf{Backend} je postavený na Django 5.0 s Django REST Framework pre RESTful API. PostgreSQL 16 slúži ako primárna databáza s podporou JSONB pre flexibilné ukladanie metadát a full-text search pre vyhľadávanie úloh.

\textbf{Integrácie} zahŕňajú Google Calendar API pre správu udalostí, Google Tasks API pre synchronizáciu úloh a Google Gemini API pre AI-powered odporúčania a automatickú kategorizáciu úloh.

\subsection{Kľúčové funkcionality}

\begin{enumerate}
\item \textbf{Inteligentná prioritizácia}: Gemini analyzuje deadline, náročnosť a kontext úlohy a navrhuje optimálny čas na jej splnenie.
\item \textbf{Automatická synchronizácia}: Obojsmerná synchronizácia s Google Calendar a Tasks zabezpečuje konzistenciu dát.
\item \textbf{Vizuálny prehľad}: Dashboard zobrazuje denný/týždenný plán s farebným kódovaním podľa Eisenhowerovej matice.
\item \textbf{Pomodoro timer}: Vstavaný časovač s notifikáciami a sledovaním produktivity.
\item \textbf{Kolaborácia}: Zdieľanie projektov a úloh v rámci študentských tímov.
\end{enumerate}

\subsection{Indexy a optimalizácie}

Pre efektívne vyhľadávanie sú vytvorené nasledujúce indexy:

\[
\begin{aligned}
&\text{idx\_tasks\_user\_deadline} \text{ ON Tasks(user\_id, deadline)} \\
&\text{idx\_tasks\_status} \text{ ON Tasks(status)} \\
&\text{idx\_tasks\_fulltext} \text{ ON Tasks USING GIN(to\_tsvector(title))}
\end{aligned}
\]

Časová zložitosť vyhľadávania úloh:
\[
O(\log n) \text{ pre indexované queries, kde } n = \text{počet úloh}
\]

\section{Technologické výhody}

\subsection{Next.js frontend}
Next.js 14 poskytuje server-side rendering (SSR) pre lepšie SEO a rýchlejšie načítanie, React Server Components znižujú bundle size o $\sim$30\% a App Router zjednodušuje routing a data fetching.

\subsection{Django backend}
Django ORM eliminuje SQL injection riziká, vstavaný admin interface urýchľuje vývoj a Django REST Framework poskytuje robustné API s automatickou dokumentáciou (OpenAPI/Swagger).

\subsection{PostgreSQL}
JSONB typ umožňuje flexibilné ukladanie AI odporúčaní bez potreby schema migrations, full-text search podporuje vyhľadávanie v slovenčine a ACID garantuje konzistenciu dát pri synchronizácii.

\section{Implementačné výzvy}

Hlavné technické výzvy zahŕňajú:

\begin{enumerate}
\item \textbf{Synchronizácia}: Riešenie konfliktov pri simultánnych zmenách v TIMA a Google službách pomocou Last-Write-Wins (LWW) stratégie s timestampmi.
\item \textbf{Rate limiting}: Google API majú limity (1000 požiadaviek/100s pre Calendar), je nutné implementovať request batching a caching.
\item \textbf{AI náklady}: Gemini API nie je zadarmo, optimalizácia promptov a caching odpovedí znižujú náklady.
\item \textbf{Privacy}: GDPR compliance vyžaduje šifrovanie osobných dát a explicitný súhlas používateľov.
\end{enumerate}

"use client"

import { Card, CardContent, CardHeader } 
  from "@/components/ui/card"
import { Badge } from "@/components/ui/badge"
import { Button } from "@/components/ui/button"

interface Task {
  id: string
  title: string
  priority: 1 | 2 | 3 | 4
  urgency: 1 | 2 | 3 | 4
  deadline: Date
  status: "pending" | "active" | "completed"
}

export function TaskCard({ task }: { task: Task }) {
  const getQuadrant = () => {
    if (task.priority >= 3 && task.urgency >= 3)
      return { color: "red", label: "Urgentne" }
    if (task.priority >= 3 && task.urgency < 3)
      return { color: "yellow", label: "Dolezite" }
    if (task.priority < 3 && task.urgency >= 3)
      return { color: "blue", label: "Delegovat" }
    return { color: "gray", label: "Neskor" }
  }

  const quadrant = getQuadrant()

  return (
    <Card className="hover:shadow-lg transition">
      <CardHeader className="flex flex-row 
        items-center justify-between">
        <h3 className="font-semibold">
          {task.title}
        </h3>
        <Badge variant={quadrant.color}>
          {quadrant.label}
        </Badge>
      </CardHeader>
      <CardContent>
        <p className="text-sm text-gray-600">
          Deadline: {task.deadline.toLocaleDateString()}
        </p>
        <Button className="mt-2" size="sm">
          Zacat Pomodoro
        </Button>
      </CardContent>
    </Card>
  )
}

\subsection{Django REST API endpoint}

Backend implementácia pre vytvorenie úlohy s AI analýzou:

\begin{lstlisting}[language=Python, caption=Django view pre vytvorenie ulohy]
from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.response import Response
from django.utils import timezone
import google.generativeai as genai

class TaskViewSet(viewsets.ModelViewSet):
    queryset = Task.objects.all()
    serializer_class = TaskSerializer
    
    def create(self, request):
        serializer = self.get_serializer(
            data=request.data
        )
        serializer.is_valid(raise_exception=True)
        
        # AI analyza ulohy pomocou Gemini
        task_data = serializer.validated_data
        ai_suggestions = self.analyze_with_gemini(
            task_data
        )
        
        task = serializer.save(
            user=request.user,
            ai_suggestions=ai_suggestions
        )
        
        # Synchronizacia s Google Tasks
        self.sync_to_google_tasks(task)
        
        return Response(
            serializer.data,
            status=status.HTTP_201_CREATED
        )
    
    def analyze_with_gemini(self, task_data):
        genai.configure(
            api_key=settings.GEMINI_API_KEY
        )
        model = genai.GenerativeModel('gemini-pro')
        
        prompt = f"""
        Analyzuj ulohu:
        Nazov: {task_data['title']}
        Popis: {task_data['description']}
        Deadline: {task_data['deadline']}
        
        Poskytni:
        1. Odporucanu prioritu (1-4)
        2. Odhadovany cas na splnenie
        3. Optimalny cas zacatia
        4. Rozdelenie na mensie ulohy
        """
        
        response = model.generate_content(prompt)
        return {
            'analysis': response.text,
            'generated_at': timezone.now()
        }
    
    @action(detail=True, methods=['post'])
    def start_pomodoro(self, request, pk=None):
        task = self.get_object()
        session = PomodoroSession.objects.create(
            user=request.user,
            task=task,
            duration=25,
            started_at=timezone.now()
        )
        return Response({
            'session_id': session.id,
            'duration': 25
        })

\subsection{Integrácia s Google Calendar}

Implementácia synchronizácie s Google Calendar API:

\begin{lstlisting}[language=Python, caption=Google Calendar synchronizacia]
from google.oauth2.credentials import Credentials
from googleapiclient.discovery import build

class GoogleCalendarSync:
    def __init__(self, user):
        self.user = user
        self.credentials = self.get_credentials()
        self.service = build(
            'calendar', 'v3',
            credentials=self.credentials
        )
    
    def sync_task_to_event(self, task):
        event = {
            'summary': task.title,
            'description': task.description,
            'start': {
                'dateTime': task.deadline.isoformat(),
                'timeZone': 'Europe/Bratislava',
            },
            'end': {
                'dateTime': (
                    task.deadline + 
                    timedelta(
                        minutes=task.estimated_duration
                    )
                ).isoformat(),
                'timeZone': 'Europe/Bratislava',
            },
            'reminders': {
                'useDefault': False,
                'overrides': [
                    {'method': 'popup', 'minutes': 30},
                ],
            },
        }
        
        if task.google_calendar_event_id:
            # Update existing event
            event = self.service.events().update(
                calendarId='primary',
                eventId=task.google_calendar_event_id,
                body=event
            ).execute()
        else:
            # Create new event
            event = self.service.events().insert(
                calendarId='primary',
                body=event
            ).execute()
            task.google_calendar_event_id = event['id']
            task.save()
        
        return event
\end{lstlisting}

TimeManager predstavuje moderný prístup k time managementu pre študentov, ktorý kombinuje osvedčené metodológie s najnovšími technológiami. Integrácia Google služieb a AI asistenta Gemini poskytuje inteligentné a kontextuálne odporúčania, zatiaľ čo robustný tech stack (Next.js, Django, PostgreSQL) zabezpečuje škálovateľnosť a spoľahlivosť.
